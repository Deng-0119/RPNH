Understanding this run

Where does it start?

Green task inputs are declared entry points. Purple result outputs are possible exit locations, not proof of completion. Loop-back connections are retained.

Three levels of detail

Overview shows only Agents and their next Agents. Tools, conditions, places and resources appear only in the detailed views.

Workflow cards explain each step and fold only simple data handoffs. Joins, conditions and resources remain explicit. PetriNet shows every actual place, transition and arc; numbers indicate active token counts.

How does replay work?

Drag the timeline to inspect saved canonical checkpoints. The task may continue running without pulling your view back to live. Replay covers the current net version, not unsettled intermediate states. Its scope is shown on the timeline.

States and data

Settled does not mean business success. A start record does not prove process liveness. Not provided is not zero. Movement along an arrow illustrates adjacent canonical changes; it is not an additional execution fact.

Resources and evidence

Use the resources control to show or hide dependencies. Select a step and open Evidence to inspect exact references. Names and descriptions come from separate presentation metadata and never modify agent prompts.
