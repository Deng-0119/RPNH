# U-MDT/CT-BR steering-committee task

Act as the trial statistician preparing a concise steering-committee packet
for a possible confirmatory randomized trial in multibacillary leprosy. Design
and execute a multi-agent workflow yourself; no fixed workflow is supplied.

Produce two registered deliverables from the attached article, statistical
analysis plan and participant workbook:

1. A brief design memo recommending enrollment for a two-arm follow-up trial
   with relapse as the primary endpoint. Define endpoint, horizon and analysis
   population; state alpha, power, arm-specific relapse-risk assumptions and
   the incomplete-follow-up allowance; distinguish historical planning
   assumptions from observed outcomes; finish with one total enrollment.
2. A one-page appendix containing baseline characteristics by decoded treatment
   arm and a Kaplan-Meier-style time-to-first-reaction comparison. Use `DT FIRST
   VISIT` as time zero, `DT FIRST REACTION` as the event date, and `DT LAST
   VISIT` for censoring. Add a short interpretation.

Use the `CODE BOOK` sheet. Label arms `U-MDT` and `R-MDT`, not numeric codes.
Execute calculations in the workspace and preserve the generated analysis
files. The final report must state its rounding convention and must not confuse
reaction with the confirmatory relapse endpoint.
