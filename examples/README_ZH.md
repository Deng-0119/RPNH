# RPNH 用户案例

[English](README.md) | 中文

以下案例沿同一套 RPNH 执行路径逐步展开：

1. [原生工具与登记资源](native_plugin/README_ZH.md)，不使用模型。
2. [模型—程序—模型工作流](hybrid_summary/README_ZH.md)，默认使用脚本化替身。
3. [两个独立任务](task_workspace/README_ZH.md)，由 basic 前端管理。
4. 使用 `rpnh examples export --output DIR` 导出的安装版 provider-neutral 真实任务，
   分别提供 Basic、Codex、DSH 与 OpenCode 说明。

请从[完整案例指南](../docs/guides/examples_ZH.md)开始。生成的 profile、Registry 目录和
provider transcript 均保存在仓库之外。
