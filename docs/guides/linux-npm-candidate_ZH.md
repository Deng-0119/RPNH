# Linux 安装与 npm 源码候选

本分支是源码整合候选，不是新的稳定发行。默认分支及已有发行资产保持不变。不要用本地构建的 `0.1.0rc3` wheel 覆盖已有安装：保留的版本号用于开发基线，不代表重新发布该版本。

## 本次内容

npm 薄入口调用 Python bootstrap 和原受管安装生命周期。Linux 调用监督保留原进程组并处理后代进程清理；重开会话只观察待执行工作，不暗中重新启动，执行仍需显式操作。入口同时依赖安装、前端选择、运行时/账户绑定及其原 Registry/PN 基础，因此本次并非仅修改一个 npm launcher，也涉及工具执行和 Viewer 管理的运行兼容闭包。

源码包位于 `packaging/npm-bootstrap`，其中中英文 README 说明准确前置条件和本地 tarball 命令。包仍为 `private: true`、`0.0.0-private`。当前需要本地控制器 wheel、持久 Python 和已安装的 uv，尚无已验证的公网 `npm install` 命令。仅更新薄入口包不等于升级 RPNH 应用。

## 2026-11-16 验证范围

此整合候选通过 67 项 Python bootstrap/安装契约/平台测试、7 项 npm 传输测试、Python 编译、wheel 和源码归档构建。wheel 包含 bootstrap 命令入口和候选前端清单。这些属于离线及源码验证，不是新一轮真实模型验收。

当前重新组合的公开候选需要独立的原生验收；离线检查不等于真实模型验收。当前验证环境缺少 `/proc/self/task/<pid>/children`，原生进程监督测试未能通过；没有删除防护来制造通过结果。
